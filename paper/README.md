# SEC 2026 camera-ready artifact material

This directory contains the tables, plots, and supporting report associated
with the SmartOTA-Bench SEC 2026 camera-ready artifact. The material was copied
from the validated frozen deterministic benchmark package.

- `tables/` contains generated CSV and LaTeX tables.
- `plots/` contains generated PNG and SVG plots.
- `paper_report.md` summarizes the deterministic result package.

This directory does not include or claim to include the final published
manuscript. No camera-ready PDF or LaTeX manuscript source is distributed in
this artifact.
