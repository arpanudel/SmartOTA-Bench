## BSDIFF and rsync terminology

SmartOTA-Bench uses the separately installed `bsdiff4` package to create and
apply BSDIFF-format patches. The `rsync_rolling_hash` policy is original
framework-native code using aligned fixed blocks, a weak checksum, SHA-256, and
copy/raw-insert operations. No rsync program or rsync source code is bundled,
and the policy is not a native rsync implementation.
